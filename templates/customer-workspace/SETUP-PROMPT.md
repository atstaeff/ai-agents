# Set up a project for AI-assisted engineering

Use this prompt from the target project's root. Preserve existing instructions and files.

```text
Inspect this project and configure a lean engineering workflow.

Use AGENTS.md as the shared entry point. Merge existing rules and link the actual
vision/scope, owners, process, repositories, issue/review system, decisions and current
knowledge. Add real setup/start/check commands. Reuse existing Markdown or authoritative
URLs; do not invent locations or introduce a mandatory workspace tree or YAML manifest.

Keep personal working plans in my privately configured Second Brain project folder,
subject to project information policy. Keep the path and vault name out of shared files.
If the location is unavailable, report that the plan is unsaved and continue with a short
session plan; do not create a repository plan or duplicate tracker automatically.

Use issues for shared scope/acceptance and PRs for code and verification. After
implementation, preserve significant decisions and update affected project knowledge.
Require no ADR, plan file or extra agent for a routine edit. Follow existing review policy.

When documentation is useful, derive it and a knowledge graph from allowlisted shared
Markdown only. Keep private notes and execution plans outside the site. Return changed
files, actual checks, unresolved setup facts and one concrete next step.
```
