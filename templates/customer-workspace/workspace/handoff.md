# Bounded handoff template

Use inside the designated work item; do not create a parallel plan or mandatory extra file.

- Updated: <time with zone>
- Assignment/source: <link and revision / last relevant feedback>
- Current scope: <agreed outcome and affected criteria>
- Repositories: <each relevant branch / PR / commit>
- Decisions and approval: <source links, status and responsible role>
- Evidence: <criterion -> actual result -> tested revision; missing checks>
- Open question / blocker: <owner, consequence and resume condition>
- Unsaved work: <none or recovery location and limits>
- Pending writes: <none or intended effect to reconcile in the original system>
- Next action: <one executable authorized step>

On resume compare these pointers with current authoritative sources. A summary is not
approval or proof of freshness. Preserve human-owned sections and feedback.
