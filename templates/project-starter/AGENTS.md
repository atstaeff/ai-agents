Use existing equivalent files or adopted web URLs when those own the information.
For central web policy, specify the adopted revision/version and read the actual source.
If a required source is unavailable, report the exact gap and continue only independent
work within existing authorization. A link neither installs a skill nor grants access.

## Ownership and coordination

Keep one work item and one live plan per assignment. Identify its accountable human,
active contributor, bounded write scope, dependencies and integration owner. A person
can hold several roles. Keep priority, feedback and blockers visible at that work home.

Use separate branches and working directories for independent writers. Agree shared
contracts before dependent implementation. Coordinate overlapping scopes using the
project's shared claim/handover mechanism; serialize overlapping writes when it is absent.
An assignee or branch is no atomic lock. Preserve others' changes and reread shared
records before updates. Delegate only when supported, authorized and useful.

## Delivery and verification

Follow the contribution process and select relevant skills explicitly. Proceed with
routine reversible choices in scope; resolve consequential scope, architecture, interface,
security, cost or operational changes with the responsible owner.

Implement reviewable increments in the established stack. Run actual project checks,
verify affected behavior and failure cases, and record evidence against the tested revision.
Coordinate integration order and verify the combined result after changes are combined.
Apply required review/acceptance to the current revision. Report unrun and blocked checks.

## Knowledge and handoff

Update affected current knowledge and record significant decisions as they arise.
Preserve context, alternatives, rationale, consequences, owner and status. Link accepted
replacements; retain completed plans as history at their work home.

Before a pause or writer/model switch, save result, relevant revisions, evidence/limits,
blockers, pending writes and one next action in the same assignment. On resuming, verify
current sources before acting on the last handoff. Use English for shared artifacts and
the user's language in conversation. Follow actual project and host action permissions.
