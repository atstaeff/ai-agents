## Working method and AI process

Follow [CONTRIBUTING.md](CONTRIBUTING.md). The default is clarify, plan when useful, build,
verify, then required acceptance/integration and knowledge retention. The guide links
reusable skills and actual commands; AGENTS.md supplies source navigation and collaboration rules.
Small fixes need no phase documents. Record an adopted alternative method and its
authoritative instructions in the contribution guide.

## Resume work

Read the current assignment and feedback, affected knowledge/contracts/decisions, then
the last bounded handoff. Check source revisions and actual evidence; search the scoped
project for missing links. Before a pause, save result, revisions, evidence/limits,
blockers, pending writes and one next action at the appropriate private or shared home.
The shared assignment and project knowledge must let a teammate continue without a private plan.
