# Project instructions

Start with [workspace/README.md](workspace/README.md) and
[workspace/workspace.yml](workspace/workspace.yml). Keep shared artifacts English;
use the user's language in conversation. Preserve existing project rules and technology.

For a small clear correction, inspect, change and run relevant checks directly. For larger
work, keep acceptance, short plan, feedback, evidence and handoff in the assigned work item.
Use one local `workspace/work/` record only when no designated tracker owns the assignment.

Read affected contracts, current knowledge and decisions; search if links are missing.
Capture significant rationale when it arises. Keep proposed, accepted, implemented and
verified states distinct. Update affected current knowledge from actual evidence.
Before a pause, save source revisions, result, limitations, blockers, pending writes and
one next action at the existing planning home. Session links are optional navigation aids.

One session is the default. Delegate only if supported, authorized and useful, with
bounded scopes and an integrator. Preserve human comments and check current files before
updating them. Resolve consequential conflicts with the accountable owner; continue
independent authorized work. Follow required plan review and actual host permissions.

Report changes, checks and remaining gaps. No invented results, approvals or tool access.
Merge, deployment, messages and destructive actions need the appropriate authorization.
