# Agent source template

Create `agents/<domain>/<name>.agent.md`. Give the role a clear selection situation and
bounded responsibility; actual tools and permissions belong to the host adapter.

```markdown
---
name: "replace-with-name"
description: "Select for a concrete outcome or uncertainty that this role owns."
---

# Role title

## Responsibility

State the bounded outcome, applicable project authority and expected handoff.
Follow the shared workflow through a correctly rebased source link.

## Procedure

1. Inspect the assignment, relevant sources and constraints.
2. Apply the narrowest useful expertise within scope.
3. Return the result, evidence, material findings and next authorized step.

## Relevant skills

Link selected canonical skills rather than copying their instructions.
```
