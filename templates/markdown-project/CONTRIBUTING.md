## Policy adoption

The [local process](engineering/process/README.md) governs by default. If adopting external
policy, record the immutable source URL, full revision or governed documentation version,
applicable scope and any approved fallback. Read the applicable procedure bodies at the
same revision; pin separate binding sources explicitly. A live guide can supply techniques
without adopting its policy. When required material is unavailable, name the affected
action and continue independent authorized work.
