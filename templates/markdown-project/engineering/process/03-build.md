# 03 — Build

Use for authorized implementation. Read the bounded assignment, affected source/contracts,
applicable decisions and selected [skills](../skills/README.md).

- Match the existing stack and implement a reviewable increment against acceptance.
- Preserve other writers' edits; coordinate shared interfaces and overlapping scopes.
- Use tools for mechanical work, delegate independent slices under the shared process
  contract, inspect returned changes and integrate them in an explicit order.
- Record newly significant reasons when they arise; do not silently override accepted ADRs.

Result: reviewable changes linked to the assignment. Continue to [verify](04-verify.md).
Return to [plan](02-plan.md) when evidence changes a consequential design assumption.
