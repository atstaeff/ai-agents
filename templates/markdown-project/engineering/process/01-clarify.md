# 01 — Clarify

Use when the requested outcome, affected users or acceptance is uncertain.
Read the assignment, relevant project goals/boundaries and affected existing behavior.

- Define the smallest useful outcome and observable acceptance at the existing work home.
- Identify the accountable owner, constraints and missing facts that can change the result.
- Resolve consequential uncertainty with that owner; continue independent authorized work.
- Use relevant discovery techniques from the [skill map](../skills/README.md) only as needed.

Result: bounded scope and acceptance, with unknowns stated. Continue to
[plan](02-plan.md) if design/coordination is needed, otherwise [build](03-build.md).
A direct clear request needs no extra intake document.
