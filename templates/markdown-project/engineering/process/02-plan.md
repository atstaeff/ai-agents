# 02 — Plan

Use for consequential design, dependencies or substantial coordination. Read acceptance,
affected contracts, relevant [ADRs](../decisions/README.md) and current source behavior.

- Choose a bounded approach; compare material alternatives and failure/recovery paths.
- Record significant rationale in an ADR when it arises, with actual status and owner.
- Agree shared interfaces before dependent work. Assign explicit writer scopes and an
  integration owner using the [agent map](../agents/README.md) and shared process rules.
- Keep personal execution details private; put coordination collaborators need at the
  agreed shared work home. Plan checks against acceptance and actual project commands.

Result: enough design and ownership to proceed, not a compulsory planning artifact.
Continue to [build](03-build.md), or [clarify](01-clarify.md) if a required decision blocks it.
