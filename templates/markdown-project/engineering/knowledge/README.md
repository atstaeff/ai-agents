# Current project knowledge

Create pages only for useful current contracts, architecture, operations and recovery
knowledge that another person/session needs. Link relevant source revisions, verification
and [ADRs](../decisions/README.md); distinguish observed facts from assumptions.

Maintain a small topic/component index as pages appear. Load affected topics on demand.
Update living descriptions when behavior changes and preserve historical decision reasons
in ADRs. Runtime auto-memory is a derived aid: verify freshness and authority, and promote
verified shared facts to their owning source. It is not the sole project memory.

Publish selected canonical Markdown through the chosen documentation site. The rendered
site is a reading view, not a second editable source. Exclude private plans, credentials,
transcripts and local work. Shared handoffs must work without access to personal notes.
