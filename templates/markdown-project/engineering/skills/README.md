# Project skills

List only reusable techniques the project needs. Link an installed catalog entry or its
canonical SKILL.md body; keep one maintained source. For example, map Python implementation,
architecture decisions and review to the selected catalog skills during adoption.

Use this map's task descriptions to select a skill, then explicitly load only that body
and necessary references. Do not preload the entire catalog. Project process owns workflow
and permissions; skills own technique. A folder or link does not install a host skill.
Add a local skill only for an actual project-specific capability, with a clear trigger,
inputs, procedure and observable result. Host discovery/packaging is configured separately.
