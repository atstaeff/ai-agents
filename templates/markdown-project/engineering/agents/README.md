# Project agents

Map actual project tasks to needed leads and specialists, with canonical role/profile
sources and supported host bindings. Roles can be combined; do not create a role per step.
Use a delivery lead for coordination, an architecture lead for consequential design and
bounded implementation/review specialists where useful. Adapt this selection to the work.

The [process contract](../process/README.md) owns autonomous dispatch and resource rules.
Keep provider/model credentials and routes in the appropriate host configuration. Verify
availability and capability before use; a Markdown role profile alone spawns no agent.
Every delegated assignment needs a bounded outcome, write scope, dependencies, acceptance,
return evidence and integration owner. The lead remains responsible for the combined result.
