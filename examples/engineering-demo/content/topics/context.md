# Context and session continuity

## What AI and maintainers need to know

Start from `AGENTS.md`, the actual assignment, relevant decisions and current code/tests.
Load selected skills and affected knowledge instead of the entire conversation or archive.

## Personal versus shared

The original contributor may resume from a private plan. A teammate resumes from the
issue, PR, shared sources and a concise handoff. Save current revision, actual checks,
blockers and one next action. Resolve material contradictions by scope and authority,
not by whichever file was modified most recently.
