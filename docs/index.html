    AI Agents · Engineering with shared knowledge

    Build products. Preserve the reasoning.¶

    A curated expertise catalog and a practical operating model for people working with AI. Clear ownership, focused delivery and evidence that another session can continue from.

    Choose expertise Adopt the operating model

    Two parts that work together¶

    • Manage expertise

      Organize roles and reusable skills by discipline. Maintain one source and export it to OpenCode, Claude Code or Copilot.

      Explore the catalog

    • Deliver with a shared operating model

      Frame outcomes, decide consequential tradeoffs, verify small increments and preserve project knowledge where the team owns it.

      Follow the operating model

    • Make quality observable

      Connect maintainability, security, recovery and other important qualities to scenarios, checks and evidence on specific revisions.

      Engineering quality

    • Use the right artifact

      Start from a focused request, decision, architecture review, verification or handoff template, only where the project needs it.

      Choose a template

    A useful path for each responsibility¶

    Your responsibility First step Next useful source
    Engineer Choose focused skills Quality standard
    Architect Architecture expertise Decisions and reviews
    Product owner or project manager Operating model Project brief and iteration review
    Team adopting AI Adopt a workspace Setup prompt
    Catalog maintainer Manage expertise Contributing

    Small context, durable knowledge¶

    Give a new person or session the actual assignment and shared entry points. Keep the live plan in one issue/ticket, significant rationale in ADRs, implementation evidence in linked changes and a bounded handoff at the existing planning home.

    Try the actual toolkit¶

    Seven disciplines · Canonical profiles · Python 3.11+ core runtime

    The local dashboard filters expertise and edits optional Markdown work records. Runtime adapters configure discovery; the host supplies model execution and real permissions. The toolkit includes a repeatable local workflow replay, with live integrations and installed-host behavior reported separately.
