# 01 — Clarify

Use when the outcome, scope or acceptance is uncertain. Read the assignment, affected
behavior and relevant project goals, boundaries and stakeholders.

1. Establish the smallest useful outcome and observable acceptance at the actual work home.
   Identify the accountable human, constraints and dependencies. A direct request does not
   automatically need an issue, process file or intake record.
2. Resolve consequential ambiguity with the owner; proceed with routine reversible choices
   in scope and continue independent authorized work when a decision blocks another part.
3. Select [product discovery](../../skills/delivery/product-discovery/SKILL.md) when value or
   acceptance needs analysis. Load the selected body and required sources only.

Explicit [Product Intake](../../toolkit/PRODUCT-INTAKE.md) assignments follow that workflow's
human approval before engineering handoff. That gate does not apply to an independently
authorized engineering task outside Intake.

Result: bounded scope, acceptance and stated unknowns. Use [plan](02-plan.md) for design or
coordination; otherwise proceed to [build](03-build.md). No new document is mandatory.
