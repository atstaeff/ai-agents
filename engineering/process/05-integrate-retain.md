# 05 — Integrate and retain

Use for integration, completion or a handoff. Read current review/check evidence and actual
action authorization. The lead remains responsible for the combined result.

1. Prepare the reviewable change with [PR crafting](../../skills/delivery/pr-crafting/SKILL.md).
   Integrate, merge, publish, message or deploy only within the actual authorization.
   Report pending actions honestly; approval, implementation and deployment are distinct.
2. Update affected current knowledge from verified behavior. Reconcile significant decisions
   with actual acceptance, consequences and implementation/evidence links. Preserve old reasons
   and authorized replacement links. Use the [knowledge lifecycle](../../toolkit/PROJECT-KNOWLEDGE.md)
   and the project's decision template; not every edit needs an ADR.
3. Keep shared outcomes and feedback at their work home, personal plans historical in their
   private home. Close work only at the agreed completion point. Publish only selected shared
   sources; never publish private paths, plans, transcripts or credentials.
4. When pausing or handing over, save result, revisions, evidence/limits, blockers, pending
   writes and one next action at the appropriate shared/private home. Shared handoff must let
   a teammate continue without private notes. Use an existing section; no separate iteration
   report, handoff file or knowledge page is required for every task.

Result: a reviewable or authorized integrated outcome with recoverable reasons and current
knowledge. Further work follows the [process index](README.md) according to its actual need.
