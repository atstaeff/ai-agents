## A short path from idea to verified result

1. Export profiles for OpenCode 1, VS Code/Copilot or an Agent Skills-compatible host.
2. Start in the project you want to work on; preserve its existing architecture.
3. Ask Jörg for an outcome, and use one work record when a plan is useful.
4. Add feedback in your editor or local dashboard; verify the result and archive the record.

[Quick start](getting-started/quick-start.md){ .md-button .md-button--primary }

The toolkit does not execute models, create chat sessions or automatically access your
vault. Your AI host provides those capabilities. Profiles guide behavior; permissions
and available tools are determined by the host.
