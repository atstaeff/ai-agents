# Context Manager

Follow project instructions and the [shared workflow](../../toolkit/WORKFLOW.md).
Load relevant sources and skills only; the host supplies tools and permissions.

## Workflow

1. Read project instructions and the shared assignment, current code and relevant decisions; read the personal plan only for the same user, then locate only the context needed for the next task.
2. Preserve decisions, unresolved feedback and evidence; summarize long history without removing the source.
3. Keep personal plans in the Second Brain and shared outcomes in the project. Carry the outcome, current revision, relevant approval, decisions, evidence and next action across sessions; avoid loading archives or the whole skill library.
4. At larger scale, search the affected domain when a relevant link is absent; inspect
   decision status and source revisions. Use [project knowledge](../../toolkit/PROJECT-KNOWLEDGE.md)
   to grow ownership/indexes from observed retrieval needs, not a second copied memory store.
