# Choose expertise by outcome

Agents define roles and expected handoffs. Skills provide focused procedures. Start with
the current assignment and its uncertainty, then select the narrowest useful expertise.
A large catalog is available on demand; it is not mandatory context for every request.

| Discipline | Typical outcome |
| --- | --- |
| [Foundations & Coordination](general.md) | Choose expertise, plan a bounded increment and integrate results |
| [Product & Project Management](delivery.md) | Validate a problem, manage scope, flow and stakeholder decisions |
| [Architecture & Systems](architecture.md) | Model domains, contracts and consequential tradeoffs |
| [Software & Platform Engineering](engineering.md) | Implement maintainable applications, platforms and specialized products |
| [Programming Languages](languages.md) | Apply language and framework practices |
| [Quality, Security & Reliability](quality.md) | Verify behavior, review risk and exercise failure recovery |
| [Knowledge & Communication](knowledge.md) | Preserve project memory and explain outcomes |
