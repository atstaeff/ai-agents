# Catalog guidelines

Follow the repository's root [AGENTS.md](../project/agents.md),
[project facts](../repository-workspace.md) and [contribution process](index.md).
These pages publish the maintained sources; edit the source linked by each page.

- Give each role or skill a concrete selection situation and observable result.
- Improve an existing entry before adding overlapping responsibilities.
- Keep portable expertise separate from host tools, permissions and model settings.
- Keep customer facts, private plans, credentials and generated bundles out of the catalog.
- Preserve feedback and report actual evidence and limits for the current revision.

Use the [catalog guide](../catalog/maintain.md) for canonical paths, metadata, presets
and checks. [Add an agent](new-agent.md) or [improve a skill](new-skill.md) only when the
catalog needs that distinct expertise.
