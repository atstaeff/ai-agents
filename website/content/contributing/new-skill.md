# Add or improve a skill

A skill provides a procedure and focused expertise. Inspect existing metadata to avoid a
second skill for the same selection situation. Use the narrowest useful scope.

Create `skills/<domain>/<name>/SKILL.md` from the
[skill template](../templates/catalog/skill-template.md). Keep portable name/description
metadata, actionable steps and concrete completion evidence. Put substantial examples
in its `references/` directory and link them from the entry. Keep customer facts out.

Validate the skill, refresh the skill index, test native exports and build the docs.
Forward-test substantial changes on realistic raw inputs, missing access and a small
bypass task. Preserve uncertainty and report what actually ran.

The [catalog guide](../catalog/maintain.md) covers contribution and compatibility.
The website generates pages and navigation directly from the canonical metadata.
