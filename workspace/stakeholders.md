# Repository stakeholders and decision roles

The catalog and operating model serve developers, architects and project managers
using AI in engineering work. Their needs are clear guidance, maintainable software
and recoverable project knowledge. Decision and acceptance roles are explicit below.

| Role | Owner | Responsibility |
| --- | --- | --- |
| Repository, product and technical owner | [atstaeff](https://github.com/atstaeff) | Priority, consequential decisions, acceptance and authorized integration |
| Assigned contributor | Current request or assigned issue | Bounded implementation, evidence and handoff |
| Reviewer | Owner-selected reviewer on the PR | Review the current revision and report findings |

Use the assigned issue or PR for repository collaboration within actual authorization.
A role listed here does not authorize unsolicited messages, reviewer requests or approval
on another person's behalf. For direct conversation work, return questions to the requester.
