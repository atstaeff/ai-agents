# Progress Sync

## Workflow

1. Read the project-designated work item and relevant recent changes rather than reconstructing a narrative from memory. If access is unavailable, label any supplied snapshot and prepare an unsent update without claiming synchronization.
2. State completed outcomes with evidence, current blockers and the next useful action.
3. Preserve feedback and distinguish planned, in-progress, blocked and verified tasks.
4. Update the existing record and provide a concise audience-appropriate summary.

## Completion

Return the concrete result, verification evidence and any material unresolved limitation. Keep documentation proportional to the change and preserve human feedback.
