# Principal Engineer Decisions

## Workflow

1. State the problem, hard constraints and what success looks like.
2. Compare a small set of viable options including the current approach using evidence, cost, reversibility and operating burden.
3. Choose a proportionate solution; include a migration/rollback path and the condition that would justify revisiting it.
4. Record the decision in the current work file or an existing ADR location; avoid a second competing decision log.

## Completion

Return the concrete result, verification evidence and any material unresolved limitation. Keep documentation proportional to the change and preserve human feedback.
