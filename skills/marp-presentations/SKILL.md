# Marp Presentations

## Workflow

1. Define the audience, intended decision and narrative before styling slides.
2. Use valid Marp frontmatter and the repository's available templates; keep one main message per slide.
3. Prefer concise headings, readable type and relevant visuals. Do not invent facts or citations.
4. Render with the available Marp toolchain and check layout, contrast and overflow. Report if rendering is unavailable.

## Completion

Return the concrete result, verification evidence and any material unresolved limitation. Keep documentation proportional to the change and preserve human feedback.
