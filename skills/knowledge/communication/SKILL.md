# Communication

## Workflow

1. Lead with the result, requested decision or current blocker; explain the evidence and practical consequence next.
2. Use the audience's language and distinguish facts, assumptions and recommendations.
3. Ask only questions whose answers change the next step. Provide a concrete draft before requesting publication approval.
4. Do not send messages, invitations or notifications without an explicit request to send them.
5. Check that the draft preserves source meaning and original feedback, names the
   decision/action owner and labels proposed dates or outcomes. Report an unsent draft
   accurately; no response or tool failure establishes agreement.
