# Prototyping

## Workflow

1. Name one uncertainty, a time budget and the evidence that would change the decision.
2. Build the smallest representative interaction using the tools already available.
3. Keep experimental code isolated when it is not intended for production. Mark shortcuts and disposal conditions.
4. Capture observations, decide what to keep and identify the next smallest experiment.

## Completion

Return the concrete result, verification evidence and any material unresolved limitation. Keep documentation proportional to the change and preserve human feedback.
