# Resume an interrupted change

1. Read `AGENTS.md`, the current request/issue, worktree changes and relevant decisions.
2. For your own unfinished work, read the existing private plan if available. For a team
   handoff, use the issue, PR and shared sources; a private plan is not a prerequisite.
3. Compare the saved revision with current code, feedback and decisions. Refresh only
   affected context; old green checks and approvals apply only to their tested scope.
4. Continue with one concrete authorized step. If a required source is inaccessible,
   state the gap and continue independent work without inventing status or approval.

## Save only useful recovery state

Keep the outcome, branch/commit, completed checks, blockers, unsaved changes, pending
external writes and one next action in the personal plan. Include actual required
approval references when applicable. Do not copy an entire conversation.
For an actual teammate handoff, provide the same bounded information in the existing
assignment using the [handoff template](../examples/document-portal/workspace/handoff.md).
Publish only what is needed for collaboration, with private context removed.

Preserve intervening edits and human comments. Inspect remote effects before retrying a
timed-out write. Resolve consequential contradictions by scope and decision authority,
not simply by latest timestamp. Verify affected behavior after changing implementation.
See the [shared workflow](WORKFLOW.md) for execution and completion.
